# Current feature boundaries

All ten feature areas in the [feature guide](features/README.md) are implemented for a local-first archive. The original 25 audit findings remain fixed; see [the earlier verification](audit/README.md).

- Records and files belong to a browser origin. There are no accounts, server database, permissions, remote backup or automatic cross-device synchronization. Contributions use portable reviewed files, with self-reported author names. Export a **media ZIP** for a complete durable copy; JSON contains no file bytes. The automatic backup is one rolling metadata snapshot.
- Attachments use IndexedDB with 100 MB/file and 500 MB/ZIP limits. Browser quota, private mode and memory limits apply. Detached files stay for recovery and can consume space. Image/PDF/audio/video support depends on browser codecs/viewers; there is no OCR, face recognition, file conversion or cloud storage.
- Oral history records through the browser microphone API on secure contexts (HTTPS or local development). Optional live speech recognition depends on the browser/service and may send audio to that service after explicit activation. Uploaded audio requires manual transcript text. No third-party transcription or AI credentials are configured.
- Life story drafts use recorded facts; they are not externally researched or AI-generated. Printing relies on the browser’s print dialog and Save as PDF destination. Available local photos are embedded; missing files are omitted.
- The original migration map retains its static pins and historical route cards. The new journey view follows recorded stops; imported places need manual placement. The connected tree supports focus, pan/zoom and collapse with a simple row layout, not a full professional pedigree layout engine. Kinship uses all recorded parent links, including adoption/step-parentage, and is not genetic analysis.
- GEDCOM support covers common UTF-8 individual/family/source fields. It is not full conformance or lossless GEDCOM round-trip export. Unsupported tags/calendars, pointer notes and some multimedia/custom facts are not retained. Keep the original export. Approximate/range dates preserve wording but use the first/anchor year for timeline placement. Undated source catalog records use the import year.
- Notifications run only while the discoveries workspace is open and enabled for that visit. There is no background push, email or scheduled server. Anniversaries need exact month/day dates; leap-day occasions occur in leap years.
- Navigation, year and filters are in React state, not URLs. Refresh/browser Back do not restore that UI state. Unsaved editor drafts are not a separate persistent store; cancel/navigation can discard them. Saved drafts/records persist.
- External fonts and detailed map geometry have fallbacks. Tests cover Chromium on Linux and desktop/phone viewport widths, including synthetic microphone capture. Windows devices, Safari/Firefox, real touch, screen readers, live speech services and very large family archives remain unverified. Web Locks serialize supported-browser writes; unsupported-browser race behavior has not been independently verified.
- ESLint 9 remains pinned for React lint-plugin compatibility and can emit a deprecation notice. Known vulnerability counts are checked at release time, not guaranteed for future advisory updates.
